Освоение практических навыков работы с DOM-деревом: поиск элементов, динамическое изменение содержимого, атрибутов и классов без перезагрузки страницы, а также сохранение состояния интерфейса между сессиями с помощью `localStorage`[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span).

## Реализованный функционал

### 1. Поиск элементов в DOM (все 3 метода)
- `document.getElementById`: быстрый поиск элементов управления (поля ввода, кнопки добавления/удаления, переключатель темы, контейнеры метрик)[span_5](start_span)[span_5](end_span).
- `document.querySelector`: точечный поиск заголовка секции `#ideas h2` для динамического обновления счётчика[span_6](start_span)[span_6](end_span).
- `document.querySelectorAll`: выборка коллекции карточек `.idea-card` для подсчёта их количества и операции «Удалить последнюю»[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).

### 2. Динамические манипуляции с DOM
- **Создание и добавление элементов:** программная генерация карточек через `document.createElement`, наполнение разметкой и добавление в контейнер через `appendChild`[span_9](start_span)[span_9](end_span)[span_10](start_span)[span_10](end_span).
- **Удаление элементов:** удаление конкретной карточки по кнопке «Удалить» через метод `.remove()`, а также удаление последней карточки из списка[span_11](start_span)[span_11](end_span)[span_12](start_span)[span_12](end_span).
- **Изменение текста:** обновление счётчика в заголовке, динамическая подстановка значений в карточки и смена надписей на кнопках через `.textContent`[span_13](start_span)[span_13](end_span)[span_14](start_span)[span_14](end_span).
- **Изменение атрибутов:** установка атрибутов идентификации `data-id` и состояний доступности `aria-pressed`, `aria-expanded` через `.setAttribute`[span_15](start_span)[span_15](end_span).
- **Управление классами:** переключение классов `dark-theme` для стилизации темы и `hidden` для сокрытия блока через `.classList` (`add`, `remove`, `toggle`)[span_16](start_span)[span_16](end_span)[span_17](start_span)[span_17](end_span).

### 3. Интерактивные возможности (Вариант 16)
- **Карточки идей стартапов:** содержат поля — название идеи, целевая аудитория, метрика и кнопку «Удалить»[span_18](start_span)[span_18](end_span).
- **Кнопка «Добавить идею»:** создаёт карточку на основе введённых данных (или использует резервный шаблон при пустых полях)[span_19](start_span)[span_19](end_span).
- **Кнопка «Удалить последнюю»:** удаляет последний добавленный элемент списка идей[span_20](start_span)[span_20](end_span).
- **Кнопка «Скрыть идеи» / «Показать идеи»:** скрывает и восстанавливает видимость блока карточек по клику[span_21](start_span)[span_21](end_span)[span_22](start_span)[span_22](end_span).
- **Переключение темы (светлая / тёмная):** кнопка в шапке инвертирует цветовую палитру страницы без перезагрузки[span_23](start_span)[span_23](end_span)[span_24](start_span)[span_24](end_span).

### 4. Сохранение состояния в `localStorage`
- При добавлении или удалении карточек актуальный массив сериализуется в JSON и сохраняется по ключу `startup_ideas_v16`[span_25](start_span)[span_25](end_span)[span_26](start_span)[span_26](end_span).
- Выбранная цветовая тема (`light` / `dark`) сохраняется по ключу `startup_theme_v16`[span_27](start_span)[span_27](end_span)[span_28](start_span)[span_28](end_span).
- При перезагрузке страницы (`F5`) или закрытии вкладки данные восстанавливаются из `localStorage`, сохраняя интерфейс в актуальном состоянии[span_29](start_span)[span_29](end_span)[span_30](start_span)[span_30](end_span).

### 5. Обработка ошибок
- Проверка существования элементов перед обращением: функция `getEl()` валидирует наличие узла в разметке и логирует предупреждение в случае отсутствия, защищая скрипт от падения[span_31](start_span)[span_31](end_span).
- Все операции с `localStorage` и парсинг JSON обёрнуты в конструкции `try...catch` для защиты от исключений в приватном режиме или при повреждении данных[span_32](start_span)[span_32](end_span).
